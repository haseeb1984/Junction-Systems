PK Store Theme v1.0.1
=====================
Requires: WordPress 6.4+, WooCommerce 8.0+, PHP 8.2+

INSTALLATION
1. Upload ZIP via Appearance > Themes > Add New > Upload Theme
2. Activate the theme
3. Go to Store Operations > Setup Wizard
4. Enter your API credentials tab by tab
5. Done — your store is ready

WHAT'S INCLUDED
- JazzCash payment gateway (full HMAC-SHA256)
- EasyPaisa payment gateway (full SHA-256 IPN verification)
- CoD OTP verification via Twilio or local Pakistan SMS
- TCS, Leopards, Trax courier integration with circuit breaker failover
- AI chat assistant (Dukaan AI) with SSE streaming, Urdu + English
- Store Operations admin dashboard
- City Mapping manager (20 cities pre-seeded)
- Physical AND digital product support
- CoD automatically disabled for digital-only carts
- Zero jQuery, zero bloat
